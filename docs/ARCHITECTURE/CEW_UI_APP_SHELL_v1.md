# CEW UI App Shell v1

CEW deve presentarsi come workspace applicativo, non come pagina diagnostica.

## Struttura
- sidebar persistente con progetto N12 e stato runtime;
- dashboard con metriche operative;
- coda revisioni evidenze filtrabile;
- scheda revisione a due colonne: contesto evidenza + decisione umana;
- risultato leggibile con dettaglio tecnico secondario;
- responsive desktop/mobile.

## Invarianti
- la UI non è authority ingegneristica;
- Neon resta audit append-only;
- nessuna scrittura canonica dal browser;
- i quattro task F7 restano indipendenti.
