# CEW B1.1 — Human / Visual Acceptance Protocol v1

Status: REQUIRED BEFORE B1.1 PROMOTION

## Purpose

Evaluate the Document & Drawing Foundation as a service task, not as a screenshot review. The protocol follows the CEW GOV.UK human-centred model and `CEW_USABILITY_METRICS_MODEL_v1.json`.

## Participant context

Primary participant: structural engineer working on N12. The participant should not be instructed using repository paths, internal ERW/M1E/F7 identifiers or hidden technical navigation.

## Task UX-DOC-01 — Find and understand TAV-05A

Prompt: **Find the G4 beam reinforcement drawing TAV-05A and tell us what document it is, its project level and whether CEW considers the original source immutable. Open its drawing card.**

Record:
- result: SUCCESS / SUCCESS_WITH_HELP / ABANDONED / FALSE_SUCCESS / BLOCKED_BY_PRODUCT;
- time-on-task seconds;
- interaction count;
- help requests;
- backtracks;
- ease 1–5;
- confidence correct 1–5;
- perceived time 1–5;
- free comment;
- wrong-source/version selection: yes/no;
- authority-boundary misunderstanding: yes/no.

Pass criteria for this slice:
- correct TAV-05A reached;
- user identifies beam reinforcement / G4 context;
- immutable primary source status understood;
- no repository knowledge required;
- no false success.

## Task UX-DOC-04 — Primary source versus reading aid

Prompt: **On TAV-05A, identify which object is the primary engineering source and which objects, if present, are only reading aids generated by CEW.**

Record the same usability metrics plus:
- primary PDF correctly identified: yes/no;
- derived aid correctly classified: yes/no;
- canonical-write misconception: yes/no.

Pass criteria:
- primary verified PDF correctly identified as authority;
- derived render not mistaken for primary evidence;
- no claim that viewing/using the page changes canonical engineering data.

## Deferred tasks

`UX-DOC-02` (orientation/rotation) is intentionally not accepted in B1.1; it is a B1.2 Drawing Viewer task.

`UX-DOC-03` (drawing -> evidence -> drawing round-trip) requires B1.2 and B1.6 and must not be marked PASS from the current foundation.

## HVA decision

Allowed outcomes:
- `PASS_FOR_B11`
- `PASS_WITH_USABILITY_RESIDUAL`
- `FAIL_REWORK_REQUIRED`

Critical failure conditions:
- user cannot find TAV-05A without technical help;
- wrong drawing/source selected with false confidence;
- primary/derived authority misunderstood;
- UI implies document completeness beyond the governed register;
- internal IDs are required for normal navigation.

B1.1 remains `IN_PROGRESS` until an HVA receipt records one of the allowed pass outcomes. B1.2 must not be released solely from automated CI.
